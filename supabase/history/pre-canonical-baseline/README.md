# Pre-canonical Supabase SQL history

These SQL files are preserved as historical evidence from before the canonical local baseline was reconstructed.

They are incomplete, are not the active local reset path, and must not be replayed automatically. Several timestamped filenames differ from the authoritative production migration-history timestamps. The loose SQL files also record manual or superseded experiments whose production application cannot be inferred from the repository alone.

The active reset path is `supabase/migrations/`, whose 26 timestamps align with the verified production migration history and whose final migration reconstructs the current production structure from authoritative metadata.
